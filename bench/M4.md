# M4: packaging and release (2026-11-01)

- `app/build.sh`: universal app + CLI (x86_64 + arm64; Rust per target, swiftc per arch,
  `lipo`). `ARCHS=x86_64` for quick local builds. Icon from `packaging/make-icon.swift`.
- `packaging/package.sh`: `dist/SpaceSense-<v>.zip`, `.dmg` (drag to Applications),
  `spacesense-cli-<v>.tar.gz`, `SHA256SUMS`.
- CI (`.github/workflows/ci.yml`): tests + universal build + CLI smoke test on
  `macos-latest` (Apple Silicon) and `macos-15-intel`. First run: both green.
- Release v0.1.0: https://github.com/amarpathak/spacesense/releases/tag/v0.1.0.
  Re-downloaded: checksums OK, signature valid, both architectures present.
- Signing is ad-hoc: Gatekeeper rejects on first open ("Open Anyway", documented in the
  README), and Full Disk Access resets with every update. A Developer ID ($99/yr) +
  notarization removes both; not bought yet.
- Not verified yet: a manual first launch on an Apple Silicon Mac (CI only runs tests
  and builds there).
