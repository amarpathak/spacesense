# M3: cleaning with a person in the loop (2026-11-01)

Owner requirement: **deletion is never automated; a human is in the loop for every
cleanup.** Concretely:
- Nothing is preselected. The app lists candidates (`ss_plan {"candidates":true}`)
  with every box unticked; "Tick suggested" is an explicit click and still leads to
  review.
- Two steps: tick items → "Review…" shows every exact command and path, what can't be
  undone, and blockers (an app that must be quit) → red "Clean N items" button.
- No background, scheduled or default runs. `ss_clean` refuses an empty target list.
  The CLI cleans only named targets, prints the plan, requires typing `yes` at a
  terminal, refuses when stdin isn't a TTY, and has no flag to skip that.

Execution (`core/src/clean.rs`), re-checked on disk right before each step:
path still valid (inside home, ≥ 3 components, not protected, not a symlink), apps in
`quit_apps` not running, project build folders still git-ignored. Official commands
first; caches/build folders deleted; user files (large files, review items) moved to
the Trash via NSFileManager (`core/src/trash.rs`, "Put Back" works). Each step is
measured before/after (freed = real bytes) and appended as a JSON line to
`~/Library/Logs/SpaceSense/operations.log`. The app rescans afterwards.

Tests (`core/tests/clean.rs`, fixtures only): delete-contents keeps the folder and
logs; official command runs and is measured; stale ignored node_modules deleted while
source stays; a folder that became git-tracked after planning is refused; active
projects refused; symlink swapped in after planning refused (outside target survives);
outside home / home / `/Users` refused; running app blocks; never-auto and unknown
targets refused and never offered. Trash test is `--ignored` (it uses the real Trash);
ran once, passed.

Not yet: Logs older than 30 days, Time Machine snapshots (admin prompt), per-app
cleaning from the Folders screen. Owner's real cleanup (≥ 60 GB) is the acceptance
test; nothing on the real disk has been cleaned by Claude.

## Rest of M3 (2026-11-01)

- **Clean from Folders:** "Clean…/Trash…" on rows and the folder header
  (`folder:<path>` targets). The verdict decides: Cache/Rebuilds → delete; Review →
  Trash; Don't delete / unknown → refused. Containers (Library, ~/Library/*, Desktop,
  Documents…) are refused as a whole. `.ssh/.gnupg/.aws/.kube/.azure/.docker/
  .password-store/.gcloud` are "Don't delete". The app blocks Clean while the owning
  app runs (process name in core, bundle id in Swift).
- **Logs:** `delete-old` fallback deletes only files older than 30 days.
- **Time Machine local snapshots:** `tmutil deletelocalsnapshots /` through
  osascript's administrator prompt; offered only when snapshots exist (none on this Mac
  now, so untested on real snapshots).
- New rule `chrome-ai-model` (Chrome's on-device Gemini Nano model, 8.5 GB here,
  two 4.27 GB versions).
- After cleaning, results stay on screen and refresh in the background (owner asked
  why every delete rescanned).
- Owner's first real cleanup: Docker leftover (20.3 GB) moved to the Trash at
  09:51:19 (operations.log). Space returns when the Trash is emptied.
