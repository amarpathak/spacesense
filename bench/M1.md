## Decisions made while building (not in PLAN.md)

- `.DS_Store` and other Finder metadata don't count as project activity (Finder rewrites
  them on browse; before this fix almost every project looked "2 days" old).
- A git-dirty repo is a *note*, not a skip: deleting git-ignored folders can't touch
  uncommitted work. The guard that matters is `git check-ignore`: anything not ignored
  is skipped.
- Project detection skips hidden top-level folders (`~/.nvm`, `~/.npm`, …), `~/Library`,
  `*.app` and catalog locations, and never looks inside `node_modules`, `.git`, `Pods`,
  venvs, `site-packages` (deleting e.g. `~/.nvm/.../lib/node_modules` would break global npm).
- `clean` without `--dry-run` refuses (exit 2) until M3.
